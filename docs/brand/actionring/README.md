# ActionRing icon concepts

Five original icon directions for the ActionRing app and local service. Each SVG is a 512 × 512 launcher-style mark with its background included; use the individual artwork as a starting point for app, service, or documentation assets.

| File | Direction | Idea |
|---|---|---|
| `01-orbit-pulse.svg` | Orbit Pulse | A control ring with an active orbit point and motion trail. |
| `02-tactile-dial.svg` | Tactile Dial | A precision rotary dial with a bright position marker. |
| `03-action-nodes.svg` | Action Nodes | Three physical controls connected to a central action ring. |
| `04-control-deck.svg` | Control Deck | A compact control surface with a prominent master dial. |
| `05-ar-monogram.svg` | AR Monogram | A bold A/R mark contained by a continuous ring. |

Open `preview.html` to compare the five concepts side by side. These are unselected concepts and do not change the runtime icon set.
