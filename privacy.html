Privacy policy

action-ring-home-client. Last updated 13 November 2026.

action-ring-home-client is the Google sign-in client for action-ring, a personal home-automation project that runs on the owner's own Home Assistant device at home. This policy explains what happens to Google account data when you sign in with it.

What we access

Only the Google account data covered by the permissions shown on the Google sign-in screen, and only for the home-automation feature you signed in for. The app does not ask for your Google password; Google handles sign-in and gives the app an access token.

How it is used

Data is used only to run the feature you granted access for, such as controlling or showing media on the home's TV. It is not used for advertising, profiling or any other purpose.

Where it is stored

Access tokens and any data the feature needs are stored only on the owner's Home Assistant device on the home network. Nothing is sent to servers run by this project, because there are none.

Sharing

Google user data is not sold, rented or shared with anyone, and is not transferred to third parties, except where the law requires it.

Google API Services User Data Policy

action-ring-home-client's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Keeping and deleting your data

Data is kept only while the feature is in use. You can revoke the app's access at any time at myaccount.google.com/permissions; after that the stored token stops working, and it is deleted from the Home Assistant device when the feature is removed. To ask for deletion, contact us below.

Changes

If this policy changes, the new version will be posted on this page with a new date.
